# Diary

## 1. 프로젝트 소개

PC iPad Android 내가 사용하는 여러 디바이스에서 내 일정과 일상을 기록, 관리하고
이미지나 PDF 같은 자료도 함께 관리할 수 있는 다이어리 어플리케이션을 내 취향과 사용 패턴에 맞게 만들어보고자 시작했다

## 2. 기획 배경

iPad의 기본 메모 앱, Notion, goodnotes에서는 스타일러스를 이용한 자유로운 필기에 어느정도 한계가 있었다.
일반적인 문서처럼 텍스트를 작성하면서도, 작성한 텍스트와 삽입한 이미지 위에 스타일러스로 자유롭게 메모, 표시를 할 수 있는 어플을 원했다
그리고 추가로 내가 좋아하는 캐릭터나 이미지로 테마를 꾸미는, '실물 다이어리'를 꾸미는 듯한 사용 경험을 구현하고싶었다.

## 3. 핵심 기능

- 월간, 주간, 일간 단위로 일정과 그 날의 기록을 작성하고 한눈에 확인할 수 있어야함
- 텍스트, 이미지 위에 스타일러스 펜으로 필기할 수 있어야함
- 유저가 원하는 캐릭터, 이미지 등을 활용하여 다이어리를 꾸밀 수 있어야함.
- 여러 디바이스에서 같은 기록을 열람하고 편집할 수 있어야함.

## 4. 사용 흐름

 사용자는 그날 공부했던 시간, 내용을 간략하게 Daily 페이지에 등록, 기록하고 관련된 자료를 링크한다.
데일리페이지를 스터디 플래너처럼 사용하고, 그날의 학습 완성도를 스스로 평가해서 기록하면, 자동으로 주간, 월간에서 종합 점수를 표시해준다,
일간에서 표시한 내용들이 주, 월간에서도 간소화되어 보여저 한눈에 이번주에 뭘 했는지 볼 수 있다.
틈틈히 남는 시간에 자유 페이지에서 노래를 분석한다. 가사 텍스트를 붙여넣기하고 가사 위에 직접 필기 하면서 어디를 어떻게 불러야하는지 확인한다.

## 5. 첫 구현 목표

 첫 버전에선 Daily 페이지에서의 기본 사용 경험을 확인하는 것을 목표로 잡는다.

- 가로넓이 고정에 내용 입력에 따라 세로로 자동으로 늘어나는 입력 페이지
- 이미지 추가, 이동
- 텍스트나 이미지 위에 스타일러스 등으로 필기, 드로잉
- 저장 및 불러오기
- undo기능
